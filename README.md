# ☕ Triple Peaks - Página Oficial  

Bienvenidos a **Triple Peaks**, la página oficial de nuestra cafetería, donde combinamos el diseño minimalista con nuestro amor por el café artesanal en un entorno acogedor.

---

## 📋 **Descripción del Proyecto**  

Este proyecto fue desarrollado para representar la esencia de **Triple Peaks** en un espacio digital. Los usuarios pueden:  
- 🍴 Conocer nuestra oferta de café artesanal y menú.  
- 📍 Ubicar nuestras sucursales y horarios de atención.  
- ✨ Descubrir promociones y eventos exclusivos.  

El sitio web está diseñado para ofrecer una experiencia de usuario intuitiva y atractiva.  

---

## 🛠️ **Tecnologías y Técnicas Utilizadas**  

Para el desarrollo del proyecto se usaron las siguientes herramientas y técnicas:  
- **HTML5**: Para la estructura semántica del sitio.  
- **CSS3**: Para el diseño responsivo, incluyendo el uso de **Flexbox** y estilos minimalistas.   

---

## 🌟 **Funciones Principales**  

- 🎨 Diseño moderno y responsivo que se adapta a diferentes dispositivos.  
- 🧭 Navegación intuitiva para explorar menús, sucursales y promociones.  
- 💬 Formulario de contacto funcional.
